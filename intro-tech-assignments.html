數位科技概論 — 課程作業集

本頁面展示第二週網頁開發課程實作成果，包含 HTML5 語法結構（活動 01-04）以及 CSS 版型配置與無障礙檢測（活動 05-09）。

HTML 基礎與進階實作 (活動 01 - 04)

活動 01：文字層級與標籤

HTML

運用 h1~h3、p、b、i、sub、sup 製作「水與生活」科學活動介紹頁。

<h1>水的化學式：H<sub>2</sub>O</h1>
<p><b>重要：</b> 水是生命的基礎資源。</p>
作業檔名：act01.html 查看細部頁面 ↗

活動 02：多媒體標籤與格式比較

HTML / Media

整合 img、audio、video，並比較 PNG、SVG 與 JPG 之差異，製作「自然觀察任務卡」。

<img src="images/leaf.svg" alt="樹葉觀察卡">
<audio controls src="audio/birds.mp3"></audio>
作業格式：natural_card.zip

活動 03：清單與表格

HTML / Table

使用 ul/ol 清單與 table/caption/tr/th/td 表格整理「紙橋挑戰社」活動準備頁。

<table>
  <caption>材料準備清單</caption>
  <tr><th>項目</th><th>數量</th></tr>
</table>
作業檔名：act03.html

活動 04：表單元件設計

HTML / Form

靈活運用 label、input、select、radio、checkbox、textarea 設計「放學後社團體驗表」。

<label for="club">選擇社團：</label>
<select id="club" name="club"><option>程式設計社</option></select>
作業檔名：act04.html

CSS 視覺與無障礙實作 (活動 05 - 09)

活動 05

視覺風格與色彩實驗室

設定 Typography、對比配色與外距 (margin/padding)，配合色彩實驗室驗證彩度與對比度。

可選為提交案例
活動 06

整頁版型配置

使用 Flexbox 與 CSS Grid 實作單欄、兩欄、三欄及側欄等網頁佈局結構。

可選為提交案例
活動 07

卡片排列與 Object-fit

掌握網格卡片對齊，並針對變形的圖片使用 `object-fit: cover` 統一顯示比例。

可選為提交案例
活動 08

RWD 響應式網頁設計

解決橫向破版問題，使用 `@media` 媒體查詢針對手機、平板與桌機優化體驗。

可選為提交案例
活動 09

無障礙網頁檢測與修正

使用 WAVE 檢測工具發現低對比度與缺失 label 等缺陷，優化鍵盤 Focus 焦點與放大顯示功能。

可選為提交案例
